# 🎯 나만의 Python 퀴즈 게임

## 1. 프로젝트 개요

이 프로젝트는 Python 기본 문법과 객체 지향 프로그래밍, 파일 입출력, Git 사용법을 학습하기 위해 만든 콘솔 기반 퀴즈 게임입니다.

사용자는 터미널에서 메뉴를 선택하여 퀴즈를 풀고, 새로운 퀴즈를 추가하고, 등록된 퀴즈 목록과 최고 점수를 확인할 수 있습니다.

프로그램을 종료해도 퀴즈 데이터와 최고 점수는 `state.json` 파일에 저장되어 다시 실행했을 때 유지됩니다.

---

## 2. 퀴즈 주제와 선정 이유

### 퀴즈 주제

**Python 기초 문법 퀴즈**

### 선정 이유

이번 미션의 목표가 Python 기본 문법, 클래스, 파일 입출력, 예외 처리, Git 사용법을 익히는 것이기 때문에 Python 기초 문법을 퀴즈 주제로 선택했습니다.

퀴즈를 풀면서 다음 개념들을 자연스럽게 복습할 수 있습니다.

- 변수
- 자료형
- 조건문
- 반복문
- 함수
- 클래스
- JSON 파일 저장

---

## 3. 개발 환경

- Python 3.10 이상
- 외부 라이브러리 사용 없음
- 표준 라이브러리 사용 가능
  - `json`
  - `os`
  - `random` 선택 사용 가능

2. str
3. bool
4. list

✅ 정답입니다!
3) 퀴즈 추가
사용자가 직접 새로운 퀴즈를 등록할 수 있습니다.

입력 항목은 다음과 같습니다.

문제
선택지 1
선택지 2
선택지 3
선택지 4
정답 번호

선택지 2: str
선택지 3: bool
선택지 4: list
정답 번호 (1-4): 3

✅ 퀴즈가 추가되었습니다!
추가된 퀴즈는 state.json 파일에 저장됩니다.

4) 퀴즈 목록 확인
현재 등록된 퀴즈 목록을 확인할 수 있습니다.

예시:

text

----------------------------------------
[1] Python에서 문자열을 나타내는 자료형은?
[2] Python에서 조건문에 사용하는 키워드는?
[3] 리스트 자료형을 나타내는 기호는?
----------------------------------------
퀴즈가 없는 경우 안내 메시지를 출력합니다.

5) 점수 확인
지금까지 기록된 최고 점수를 확인할 수 있습니다.

예시:

text

🏆 최고 점수: 80점
아직 퀴즈를 풀지 않은 경우에는 안내 메시지를 출력합니다.

6) 데이터 저장 및 불러오기
프로그램은 실행 시 state.json 파일에서 데이터를 불러옵니다.

파일이 있으면 저장된 퀴즈와 최고 점수를 불러옵니다.
파일이 없으면 기본 퀴즈 데이터를 사용합니다.
파일이 손상된 경우 안내 메시지를 출력하고 기본 데이터로 초기화합니다.
